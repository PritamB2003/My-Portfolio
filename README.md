# Pritam Bishal – Portfolio

Static portfolio website for **Pritam Bishal**, B.Tech **Computer Science & Engineering (AIML)**.

## Tech stack

- **HTML5**
- **CSS3** (modern, responsive layout + dark/light theme)
- **Vanilla JavaScript** (theme toggle, contact helper)

No framework or build tools are required.

## Structure

- `index.html` – main portfolio page
- `styles.css` – global styles and layout
- `package.json` – metadata and simple `start` script

## Running locally

You can open the site directly:

1. Navigate to this folder in your file explorer.
2. Double‑click `index.html` to open it in your browser.

Or using Node/npm (optional):

```bash
npm install
npm run start
```

Then open the printed local URL (for example `http://localhost:3000`).

## Deploying

You can host this folder on:

- **GitHub Pages** – push the folder to a GitHub repository and enable Pages (deploy from the `main` branch root).
- **Netlify / Vercel / Render** – create a new static site, set this folder as the project, and use `index.html` as the entry.
